# Overview

This is a simple School Admission System built using React.js for the frontend and Node.js with Express.js for the backend. The system allows applicants to apply for programs, view their application status, and receive notifications when their status is updated.

# Features

Application Form: Submit a new application with applicant details and program selection.

Application List: View all submitted applications with filtering options based on status (Pending, Accepted, Rejected).

Status Update & Notifications: Update an applicant's admission status and send them a notification with a custom message.

# Technologies Used

Frontend: React.js

Backend: Node.js, Express.js

Database: MySQLite
